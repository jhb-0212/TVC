# 软广 · 实时联网对标规则

## 对标标准

看的是内容留存和互动结构，不是转化率。播放量、带货数据拿不到，禁止编造；通过结构反推（场景怎么建、痛点怎么暗示、产品怎么带出、结尾怎么收）。

## 搜索动作

- 小红书：「{品类} 小红书 爆款 种草」「{品类} 小红书 收藏高」
- 抖音：「{品类} 抖音 生活方式 达人」「{品类} 抖音 原生内容」
- B站：「{品类} B站 品牌片」「{品类} vlog 广告」
- 海外：「{品类} Apple 广告 生活场景」「{品类} MUJI 广告」「{品类} 宜家 广告」

## 看什么数据

- 只看公开可查互动数据；重点看收藏和评论深度——收藏代表「想再看」，评论深度代表「有共鸣」，点赞数最不重要。
- 播放量拿不到就不看，禁止编造；互动数据能核实才引用，无法核实填「—」。

## 结构观察（镜头层）

场景怎么建 / 痛点怎么暗示 / 产品怎么自然带出 / 结尾怎么收，写具体到哪一秒、什么动作，写不出标「结构待验证」。

## 输出格式

按 `common/compliance-base.md` 逐条制；3 条以上；无链接标「待验证」；结尾「建议参考 X + 理由」。
