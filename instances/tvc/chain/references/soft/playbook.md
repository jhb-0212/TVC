# 软广 · 规则手册

通用规则（数值、一级违禁词、分镜字段、三模型句式）见 `references/common/`，本文件只放软广专属规则。

## 1. 四类型定义与差异对照

| 类型       | 定位                  | 适用              |
| -------- | ------------------- | --------------- |
| S1 生活记录  | vlog 式真实切片，像纪录片不像广告 | 日常用品、食品、家居、宠物   |
| S2 场景种草  | 一个具体场景 + 产品自然融入     | 母婴、通勤、办公、户外     |
| S3 情绪叙事  | 温情 / 治愈 / 反差，情绪驱动记忆 | 节日、家庭、独居、成长     |
| S4 价值观表达 | 品牌主张 / 生活态度，产品是佐证   | 服饰、美妆、健康、生活方式品牌 |

| 维度       | S1 生活记录        | S2 场景种草      | S3 情绪叙事     | S4 价值观表达  |
| -------- | -------------- | ------------ | ----------- | --------- |
| 前 3 秒抓什么 | 真实生活细节         | 场景里的一个小麻烦    | 一个情绪瞬间      | 一句反常识主张   |
| 产品怎么出场   | 自然出现在画面角落      | 解决场景问题的动作    | 承载情绪的道具     | 主张的佐证     |
| 卖点怎么讲    | 不讲卖点，讲「我平时就这样」 | 暗示，讲「用了之后顺手」 | 不讲卖点，讲「它陪我」 | 一句话带过     |
| 结尾怎么收    | 一句日常感慨         | 状态变好的微画面     | 情绪落点 + 品牌署名 | 一句可被引用的话  |
| 热点跟不跟    | 跟生活趋势          | 跟场景刚需        | 跟情感母题       | 跟社会议题（谨慎） |

## 2. 5 类钩子 + 调性池 + 4 拍写法

### 5 类钩子

1. **场景钩子**：一个让人想看的日常场景。
2. **情绪钩子**：一个共鸣情绪瞬间。
3. **悬念钩子**：一个让人好奇的细节。
4. **反差钩子**：打破刻板印象。
5. **细节钩子**：一个生活细节的特写。

### 调性池（每条脚本选 1 个，同一轮内不得出现两个同调性）

- **温情治愈**：家人、宠物、独居日常，情绪克制，微光感。
- **真实记录**：vlog 式生活切片，像纪录片不像广告。
- **轻幽默**：生活小尴尬 + 会心一笑，不夸张不吵。
- **反差感**：刻板印象打破，如「谁说一个人吃饭很惨」。
- **松弛感**：慢节奏、自然光、无压迫感的生活方式主张。

### 4 拍写法（Scene / Insight / Product / Value）

- **Scene**：建立生活切片，让人对号入座。15s 档 0–4s，30s 档 0–5s，45s/60s 档 ≤5s（段秒数查 `references/common/spec-table.md` 的 15s/30s 时间轴）。
- **Insight**：隐性痛点，用画面细节暗示，禁直白台词（禁「你是不是有 XX 问题」）。
- **Product**：通过使用动作、环境陈设、他人推荐自然带出；禁定格特写硬砸、禁产品自述卖点。
- **Value（状态转变）**：一句价值观或日常感慨，克制不说教；对应 spec-table 的「状态转变」段。

### 矩阵与反重复

- 5 钩子 × 3 场景 = 15 格；默认精选 6–9 条（覆盖 3 场景 + 尽量覆盖 5 钩子，优先高共鸣与低风险），用户明确要铺满才补 15 条。
- 3 个场景按目标人群拆，必须具体有画面（如「独居青年的下班后」「新手妈妈的第一年」「通勤族的早高峰」），不是「年轻人」「女性」这种标签。
- 精选各条之间：场景 / 钩子句式 / 产品出场方式 / 调性不得四者全同。
- 禁止「30s 只是把 15s 动作拉长」，每条时长档须新增场景细节或新信息。

## 3. 二级合规项 + 功效暗示专项 + 逐镜扫描

一级违禁词替换表见 `references/common/compliance-base.md`。本节只写二级项与软广专属风险。

### 二级项（只标🟡+建议，不擅自改）

功效暗示、数据宣称、前后对比画面、焦虑暗示、贬低竞品。

### 功效暗示专项（软广最高风险项）

- 定义：把产品与某个结果构成因果暗示，即使没说「保证」也违规。
- 典型违规句：
  - 「用了它皮肤就好了」→ 改「最近皮肤状态还不错」
  - 「喝了它就不累了」→ 改「精神好一点」
  - 「换了这个枕头再没失眠过」→ 改「睡得踏实些」
  - 「自从用了它，孩子成绩上去了」→ 直接删，改为呈现使用场景
- 改法原则：**只呈现状态，不承诺效果；只描述使用，不描述因果。**
- 每个功效暗示句必须点名落在哪一镜，并在该镜给出去因果改法。

### 其他二级风险

- **虚假场景**：摆拍冒充真实使用、假素人、假测评 → 标🔴，整镜重写。
- **儿童 / 宠物出镜** → 标🟡，提示需授权。
- **焦虑暗示**：「不 XX 就落后了」「别人都 XX 了」→ 标🟡，给去焦虑改法。
- **广告标识**：平台要求时须可识别为广告（达人标「广告/合作」，品牌自制标「品牌内容」）。

### 逐镜扫描（强制，不得跳步）

每个风险点必须点名它落在哪一镜、属于哪一类、如何处理。禁止只做总结性过审。

### 标注

每条最终标 🟢 可直接投 / 🟡 需改词改画面（附建议）/ 🔴 整条不可用（说明原因）。

## 4. 四拍归因表（投后诊断用）

| 异常指标   | 归因拍     | 定位动作              |
| ------ | ------- | ----------------- |
| 3s 留存低 | Scene   | 生活切片是否真实、有代入感     |
| 中段掉    | Insight | 痛点暗示是否够准、是否共鸣     |
| 产品段掉   | Product | 出场是否太硬、是否像广告      |
| 收藏低    | Value   | 结尾是否有可被引用 / 收藏的主张 |
| 评论浅    | 全片      | 是否只是好看，没有共鸣点      |

**诊断动作**：定位到具体镜 → 只给该拍替换建议，不推翻整条。软广看收藏率和评论深度，不是转化率。

## 5. 分镜表补充（软广专属）

10 字段与每镜校验见 `references/common/storyboard-format.md`，数值查 `references/common/spec-table.md`。本节只写软广专属要求：

- 45s 档必须满 8 行，60s 档必须满 10 行（在各自区间内），禁止合并行。
- 每条分镜表前标注：所属钩子 × 场景、类型（S1–S4）、时长档、调性、风险等级。
- 首镜时效 / 生活切片段时长 → 查 `references/common/spec-table.md` 首镜时效表，不在本文件重复维护。
- 呼吸镜头 ≤2s，全片不超过 2 处，且须标注它在承担什么（环境、表情、动作停顿），不得是无意义空镜。
- 场景钩子镜 ≤5s，轻引导镜 ≤3s。
- 五段式时间轴（45s / 60s 必标）：查 `references/common/spec-table.md`。
- 表尾必附：合计校验行（各镜加总 = 总时长，误差 ≤0.5s）+ 结构段时长分布核对（偏差 >2s 标出并说明）。

## 6. 三模型链路侧重

句式模板见 `references/common/prompts.md`。软广专属侧重：

- Kling / 可灵：自然光优先、生活场景优先，人物动作写「自然、克制、不表演」；避免「模特摆拍感」。
- Veo：英文镜头语言写清自然光（natural light / window light）与生活场景（home interior / street），人物表情写 subtle。
- Runway：参考图优先给生活场景实拍或自然光参考；运动描述轻，避免大幅运镜破坏「真实感」。
- 通用：产品出场镜禁定格特写硬砸；人物手指与表情须自然，AI 崩坏即重生成。
