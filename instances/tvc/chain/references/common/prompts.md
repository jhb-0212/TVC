# 三模型提示词句式（三链路通用）

## Kling / 可灵（中文叙事）
`镜N：画幅，主体 + 动作 + 环境 + 光影 + 运镜 + 时长。`

## Veo（英文镜头语言）
`Shot N: aspect, subject + action + environment + lighting + camera, duration.`

## Runway（参考图 + 运动）
`Shot N: Reference = ..., Motion = ..., Camera = ..., Duration = ...`

## 通用约束
- 每条标注目标模型，按该模型句式改写。
- 未指定模型：默认输出中文叙事版 + 英文镜头版各一份。
- AI 禁止：产品变形、人物手指崩坏、屏幕文字扭曲。
- 画面比例：9:16 或 16:9，无黑边。

## 链路侧重
- 硬广：屏幕 UI 文字清晰可读，产品特写不变形。
- 软广：自然光优先，生活场景优先，人物表情自然。
- 剧情：人物关系与表情是重点，光影服务情绪。
