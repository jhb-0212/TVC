| 字段 | 内容 |
|---|---|

链路专属字段（按链路填，替代方向候选里对应的差异化要素）：

| 链路 | 专属字段 |
|---|---|
| 硬广 | 核心卖点 + 核心钩子 |
| 软广 | 产品带来的改变 + 生活切片 + 产品出场方式 |
| 剧情 | 人物关系 + 冲突点 + 产品功能 |

> 方向候选（Step 4 前半）给 3 个候选时，每个候选写「调性 + 链路专属差异化要素 + 建议选 X」；用户选定后，把选定方向的字段落成上表一页纸。专属字段表即方向候选字段的落点，两者一一对应，不新增字段。

确认一页纸（用户选定方向）后再生成脚本与分镜。

## 配套交付 5 项（模块 0 之后附）

1. 独立台词稿（旁白/对白/独白分列，标角色；剧情加情绪提示）
2. 落版文案定稿（logo / slogan / CTA 文字）
3. 版本修改记录（v1/v2/v3，每次写「改了 X」）
4. 结构段时长分布核对表（每段实际时长 vs 时间轴要求，偏差 >2s 标出）
5. 参数一致性核对表（分镜 vs Step 2 确认参数，逐项 ✅/❌）

## 链路附加
- 软广：BGM 建议（只给风格描述，不给具体曲目）
- 剧情：情绪曲线图（文字版：铺垫→爆发→释放，标在哪一镜）
