## 数据引用原则

- 脚本、字幕、口播、封面中出现的任何数字，必须可核实或明确标「示例数据」。
- 无法核实的数据不引用、不标注、不出现；禁止用「未核实」作为保留借口。
- 公开可查只有点赞 / 评论 / 收藏 / 转发；播放量、GMV、转化率、ROI 第三方拿不到，一律不写。

## 逐条制对标输出格式（联网对标用）

| 案例名  | 平台 | 来源链接 | 发布日期 | 可迁移结构要素（镜头层）    | 互动数据            |
| ---- | -- | ---- | ---- | --------------- | --------------- |
| （逐条） | 必填 | 必填   | 必填   | 前3秒/记忆点/产品出场/证明 | 能核实填数值；无法核实填「—」 |

- 3 条以上；不足说明搜索局限，禁硬凑。
- 无链接 = 未检索，案例标「待验证」，不作主要依据。
- 结尾给一句「建议参考 X + 理由」。
