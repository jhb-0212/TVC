# 硬广 · 实时联网对标规则

## 对标标准

看的是跑量素材结构，不是审美。转化率、跑量、GMV、ROI 第三方拿不到，禁止编造；只通过结构反推（前 3 秒怎么开、记忆点怎么落、产品怎么出场、证明怎么给），不反推具体数字。

## 搜索动作

用可用的联网检索工具（WebSearch / WebFetch）检索，关键词按维度组合，禁止凭内部记忆编造案例：

- 平台素材库：「{品类} 跑量素材」「{品类} 巨量创意」「{品类} 千川 信息流 高转化」
- 电梯广告：「{品类} 分众 电梯广告」
- 品牌功能片：「{品类} 功能TVC」「{品类} 品牌广告片」
- 数据维度：「{品类} 爆款 点赞 评论」「{品类} 高互动 素材」

## 看什么数据

- 只看公开可查互动数据：点赞 / 评论 / 收藏 / 转发。
- 播放量、带货数据（GMV / 转化率 / 完播率 / ROI）拿不到就不看，禁止编造。
- 互动数据能核实才引用；无法核实填「—」，不以「未核实」标签保留。

## 结构观察（必须拆到镜头层）

- 前 3 秒钩子怎么开（画面 + 第一句口播，写具体）
- 记忆点做法（一句口号 / 一个动作 / 一个视觉符号，写具体）
- 产品出场方式（第几秒、正面/侧面、给不给特写）
- 证明怎么给（数据 / 对比 / 证言 / 演示）

  写不出镜头层细节就标「结构待验证」，禁止写抽象标签。

## 输出格式

按 `common/compliance-base.md` 的逐条制表输出；3 条以上；不足 3 条说明搜索局限；无链接标「待验证」；结尾给「建议参考 X，理由：……」。
