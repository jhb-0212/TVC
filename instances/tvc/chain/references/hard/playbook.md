## 硬广 · 规则手册

通用规则（数值、一级违禁词、分镜字段、三模型句式）见 `references/common/`，本文件只放硬广专属规则。

## 1. 四类型定义与差异对照

| 类型   | 定位                       | 适用         |
| ---- | ------------------------ | ---------- |
| A 测款 | 快速验证卖点 / 钩子，强 Hook 强 CTA | 新品冷启、多卖点筛选 |
| B 种草 | 场景化推荐，弱推销强信任             | 已有认知、拉转化   |
| C 剧情 | 故事驱动，情绪弧线带出产品            | 人群共鸣、破圈    |
| D·AI | AI 素材生成，画面优先             | 无实拍素材、批量产出 |

| 维度       | A 测款        | B 种草         | C 剧情        | D·AI        |
| -------- | ----------- | ------------ | ----------- | ----------- |
| 前 3 秒抓什么 | 痛点冲击 / 效果对比 | 生活氛围 / 细节反差  | 冲突瞬间 / 悬念   | 视觉奇观 / 结果前置 |
| 产品怎么出场   | 正面登场，给足特写   | 自然融入，动作带出    | 转折道具，绑定情节   | 画面主体，可虚拟化   |
| 卖点怎么讲    | 直给，可重复      | 暗示，讲感受       | 不讲卖点，讲改变    | 可视化演示       |
| 结尾怎么收    | 口号 + CTA    | 一句价值观        | 情绪落点 + 品牌署名 | 结果 + CTA    |
| 热点跟不跟    | 只跟卖点型热点     | 跟生活趋势 / 场景热点 | 跟情感母题，不追短平快 | 跟视觉趋势       |

## 2. 5 类钩子 + 调性池 + 4 拍写法

### 5 类钩子

1. **提问式**：用一个观众会答「是」的问题开场（「你是不是也……」）。
2. **反常识**：打破默认认知（「别再……了，其实……」）。
3. **身份代入**：点名人群（「XX 人注意了」）。
4. **场景痛点**：还原一个具体场景（「加班到 11 点，回家还要……」）。
5. **结果前置**：先给结果再讲过程（「3 天，我从 XX 变成 XX」）。

### 调性池（每条脚本选 1 个，同一轮内不得出现两个同调性）

- **对比打脸**：旧方案 vs 新方案，同屏审判。
- **数字震撼**：进度条、计时器、可量化证据，数字本身当记忆点。
- **痛点扎心**：把用户最烦的场景拍狠。
- **权威证言**：专业用户出场背书，讲体验。
- **反差幽默**：严肃卖点 + 轻喜剧处理。

### 4 拍写法

- **Hook**：一句口播 + 一个动作/画面，冲突或结果前置，禁铺垫。段秒数查 `references/common/spec-table.md`（15s 0–2s、30s 0–3s、45s/60s ≤3s），不在此重复维护。
- **Product**：单卖点，必须可视化——能演示、能对比、能用数据呈现，禁念参数。主打卖点唯一，其余卖点全部让位。30s 档的「痛点」并入本拍（痛点具象化是卖点的前置铺垫，不单列）。
- **Proof**：数据 / 对比 / 证言 / 演示四选一，必须有「证据感」，禁空喊「很好用」。
- **CTA**：具体到动作（「点下方」「评论区扣 1」），只承载一个动作。

**CTA 段 vs CTA 镜的口径**（避免时长算错）：
- 「CTA 段」是结构段（如 15s 的 12–15s），可含「口号镜 + 按钮镜」多个镜，段总时长按 spec-table。
- 「CTA 镜」是单个镜，每镜 ≤2s；一个 CTA 段可由 1–2 个 ≤2s 的镜组成。
- 口诀：段看 spec-table，镜 ≤2s。

**30s 四段结构与 4 拍映射**（spec-table 硬广 30s 为四段，须落到 4 拍）：

| 四段（30s）    | 归入拍   |
| ---------- | ----- |
| Hook（3s）   | Hook  |
| 痛点+产品（7s） | Product（痛点并入） |
| 证明（12s）    | Proof |
| 记忆点+CTA（8s） | CTA（记忆点并入） |

**信息密度硬约束**（skill 硬约束「每 3 秒信息推进」的落地检查）：
- 禁文艺、禁留白、禁氛围前置；每一镜必须推进一个信息（卖点 / 证据 / 动作 / 引导）。
- 自检：连续 3s 无新信息（纯空镜/纯抒情）即回改。
- 15s 档最严：无任何缓冲镜，每个镜都承担功能。

### 矩阵与反重复

- 5 钩子 × 3 痛点 = 15 格；默认精选 6–9 条（覆盖 3 痛点 + 尽量覆盖 5 钩子，优先高命中与低风险），用户明确要铺满才补 15 条。
- 精选各条之间：Hook 句式 / 核心卖点 / Proof 证据 / 调性不得四者全同。
- 旁白设唯一真源，禁止同一卖点口播重复。
- 禁止「30s 只是把 15s 动作拉长」，每条时长档须新增场景或新信息。
- 产品须参与故事因果，禁止最后突然贴片。

## 3. 二级合规项 + 行业附加 + 逐镜扫描

一级违禁词替换表见 `references/common/compliance-base.md`。本节只写二级项与扫描规则。

### 二级项（只标🟡+建议，不擅自改）

- 功效类表述：美白 / 抗衰 / 减肥 / 治疗
- 数据宣称（百分比、倍数、人数）
- 前后对比画面
- 贬低竞品

### 行业附加

- 保健品 / 食品 / 金融 / 教育 / 医美 / 母婴：追加对应免责声明与禁语清单。
- 化妆品 / 功效类：禁画面前后对比。
- 非功效类：可对比，但须标「效果因人而异」。
- AI 画面：真人形象授权、名人脸、医疗场景、儿童出镜须单独标注风险。
- 30s 及以上如需「竞品困境」段，改为「旧方案困境」或「错误用法困境」，禁止点名竞品。

### 逐镜扫描数字（强制，不得跳步）

- 产品演示数据（如「涨粉 5000」作 UI 演示）→ 标「示例数据」，避免被当成真实承诺。
- 效果宣称 / 行业数据（如「七成简历第一轮被拦」）→ 必须有来源，无来源标🟡或删。
- 互动数据（赞数 / 评论数）→ 能核实才可用，无法核实一律剔除，不出现在脚本、字幕、口播、封面中。
- 每个数字必须点名它落在哪一镜、属于哪一类、如何处理。
- 禁止只做总结性过审。

### 标注

每条最终标 🟢 可直接投 / 🟡 需改词改画面（附建议）/ 🔴 整条不可用（说明原因）。

## 4. 四拍数据归因表（投后诊断用）

| 异常指标     | 归因拍     | 定位动作                         |
| -------- | ------- | ---------------------------- |
| 3s 完播低   | Hook    | 回看 0–3s 有无动作 / 冲突 / 悬念，抽首帧判断 |
| 5s 断崖    | Product | 检查单卖点是否聚焦、是否在第 8s 前出现        |
| 评论 / 信任低 | Proof   | 检查证据是数据 / 对比 / 证言 / 演示还是空喊   |
| 点击低      | CTA     | 检查利益点是否具体、CTA 是否唯一           |
| 点击高转化低   | 承接层     | 判定为落地页 / 价格问题，非脚本问题，不硬改脚本    |

**诊断动作**：抽关键帧 → 带时间码转写 → 定位到具体镜 / 秒 → 只给该镜替换建议，不推翻整条。

## 5. 分镜表补充（硬广专属）

10 字段与每镜校验见 `references/common/storyboard-format.md`，数值查 `references/common/spec-table.md`。本节只写硬广专属要求：

- 45s 档必须满 12 行，60s 档必须满 14 行（在各自区间内），禁止合并行。
- 每条分镜表前标注：所属钩子 × 痛点、类型（A/B/C/D）、时长档、调性、风险等级。
- 首镜时效 / 钩子段时长 → 查 `references/common/spec-table.md` 首镜时效表，不在本文件重复维护。
- 15s 可选段（痛点具象化 / 卖点复述）须校验：未挤出产品段或 CTA 段的核心动作，且各镜时长加总仍 = 15s。
- 五段式时间轴（45s / 60s 必标）：查 `references/common/spec-table.md`。
- 表尾必附：合计校验行（各镜加总 = 总时长，误差 ≤0.5s）+ 结构段时长分布核对（偏差 >2s 标出并说明）。

## 6. 三模型链路侧重

句式模板见 `references/common/prompts.md`。硬广专属侧重：

- Kling / 可灵：屏幕 UI 文字必须清晰可读，产品特写不变形；演示类镜头标「固定机位」防 UI 抖动。
- Veo：英文镜头语言写清运镜与光影，屏幕类镜头加「legible UI text」约束。
- Runway：参考图优先给 UI mockup 或产品实拍图，运动描述只写屏幕内变化，避免相机运动导致文字扭曲。
- 通用：产品特写、数据展示镜禁甩镜与变焦+移动复合；超 8s 镜头标「分段生成拼接」。
