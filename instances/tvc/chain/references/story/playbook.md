# 剧情 · 规则手册

通用规则（数值、一级违禁词、分镜字段、三模型句式）见 `references/common/`，本文件只放剧情专属规则。

## 1. 五类型定义与差异对照

| 类型        | 定位                      | 适用            |
| --------- | ----------------------- | ------------- |
| T1 情感向品牌片 | 一组人物关系 + 一个情绪落点，产品是情感载体 | 节日、品牌周年、价值观输出 |
| T2 节庆大片   | 团圆 / 思念 / 重逢，情绪做满       | 春节、中秋、母亲节、毕业季 |
| T3 连载式短剧  | 强冲突 + 强悬念，可连续追          | 抖音剧情号、品牌自制短剧  |
| T4 社会议题剧情 | 替一群人说出心里话，克制不煽动         | 独居、异地、职场、代际   |
| T5 轻喜剧反转  | 生活尴尬 + 会心一笑，节奏轻快        | Z 世代品牌、3C、快消  |

| 维度       | T1 情感向      | T2 节庆       | T3 连载短剧     | T4 社会议题       | T5 轻喜剧      |
| -------- | ----------- | ----------- | ----------- | ------------- | ----------- |
| 前 3 秒抓什么 | 一个情绪瞬间      | 团圆 / 离别画面   | 冲突或悬念       | 一句替观众说的话      | 一个尴尬现场      |
| 产品怎么出场   | 情感载体，安静出现   | 团圆信物 / 思念媒介 | 解扣道具，绑定情节   | 佐证，不抢戏        | 反转道具        |
| 卖点怎么讲    | 讲「它陪我」      | 讲「它让我想起」    | 讲「它让事情有转机」  | 讲「它让生活好过一点」   | 一句轻台词带过     |
| 结尾怎么收    | 情绪落点 + 品牌署名 | 团圆画面 + 品牌署名 | 悬念钩子 / 情绪落点 | 一句克制的话 + 品牌署名 | 反转笑点 + 品牌轻露 |
| 热点跟不跟    | 跟情感母题       | 跟节庆节点       | 跟社会情绪但不追段子  | 跟社会议题（谨慎，不站队） | 跟生活尴尬       |

## 2. 5 类钩子 + 调性池 + 4 拍写法

### 5 类钩子

1. **冲突钩子**：一上来就在较劲。
2. **悬念钩子**：一个反常细节让人想知道为什么。
3. **人物钩子**：一个让人想认识的人。
4. **台词钩子**：一句让人愣住的话。
5. **反转钩子**：一个打破预期的瞬间。

### 调性池（每条脚本选 1 个，同一轮内不得出现两个同调性）

- **温情催泪**：亲情 / 爱情 / 离别，情绪做满但收得克制。
- **燃向逆袭**：被看轻的人关键时刻翻盘，爽感释放。
- **轻喜剧**：职场 / 生活尴尬 + 打工人爽点。
- **悬疑反转**：紧张氛围 + 唯一机会，大片节奏。
- **青春成长**：毕业、和解、错过与重逢。
- **社会情绪**：独居、异地、催婚、加班，替观众说出心里话。

### 4 拍写法（Conflict / Escalation / Turn / Resolution）

- **Conflict**：冲突瞬间或人物关系，必须具体可演。段秒数查 `references/common/spec-table.md` 的 15s/30s 时间轴与 45s/60s 五段式时间轴（首段），不在此重复维护。
- **Escalation**：情绪升级 / 矛盾爆发，靠表演和画面推进，不靠旁白解释。
- **Turn**：产品作为转折介入，必须承担叙事功能——删掉产品故事不成立，否则重写。
- **Resolution**：情绪自然落点，不喊口号、不做过度承诺。

**30s 六段结构与 4 拍映射**（spec-table 剧情 30s 为六段，须落到 4 拍）：

| 六段（30s）      | 归入拍     |
| ------------ | ------- |
| 人物关系         | Conflict |
| 矛盾爆发         | Escalation |
| 沉默 / 失控      | Escalation |
| 产品介入         | Turn    |
| 关系修复         | Turn    |
| 情绪落点         | Resolution |

### 矩阵与反重复

- 5 钩子 × 3 冲突 = 15 格；默认精选 6–9 条（覆盖 3 冲突 + 尽量覆盖 5 钩子，优先高共鸣与低风险），用户明确要铺满才补 15 条。
- 3 个冲突按人物关系拆，必须是具体可演的一件事（如「父子之间说不出口的话」「恋人之间的错位」「同事之间的误解」），不是「代沟」「性格不合」这种标签。
- 精选各条之间：人物关系 / 冲突类型 / 钩子句式 / 调性不得四者全同。
- 禁止「30s 只是把 15s 动作拉长」，每条时长档须新增情节或新信息。
- 台词：全片关键台词不超过 3 句，其余靠画面和表演推进；关键台词落在情绪转折处。

## 3. 7 天热点筛选规则

### 原则

只跟节庆节点与社会情绪话题，不跟娱乐八卦、灾难、政治、短期段子。热点是题材参考，不是台词素材，脚本里不出现蹭热点话术。

### 三类筛

| 类型                    | 示例                | 剧情可用性               |
| --------------------- | ----------------- | ------------------- |
| 节庆节点                  | 春节、中秋、母亲节、毕业季、开学季 | ✅ 可用，可预判，提前 2–4 周布局 |
| 社会情绪话题                | 独居、异地、催婚、加班、代际沟通  | ✅ 可用，跟话题不跟具体事件      |
| 娱乐八卦 / 灾难 / 政治 / 短期段子 | 明星绯闻、事故、争议事件、网络梗  | ❌ 不跟，破坏叙事质感且有合规风险   |

### 输出格式（逐条制，不得用概括句）

| 热点   | 类型             | 首次出现日期 | 来源链接 | 热度依据（可核实才填）     | 剧情可用性 |
| ---- | -------------- | ------ | ---- | --------------- | ----- |
| （逐条） | 节庆 / 社会情绪 / 不跟 | 必填     | 必填   | 能核实填数值；无法核实填「—」 | ✅ / ❌ |

- 无链接 = 未检索；热度依据无法核实不填，不写「未核实」。
- 检索不到或当前无联网：明确告知「无法获取近 7 天热点，请提供 2–3 条」，**禁编热搜榜、热度数值、话题阅读量**。
- 热点只用于 Step 4 方向确认时作为题材参考，不直接写进脚本台词。

## 4. 二级合规项 + 价值观红线 + 逐镜扫描

一级违禁词替换表见 `references/common/compliance-base.md`。本节只写二级项与剧情专属价值观风险。

### 二级项（只标🟡+建议，不擅自改）

消费苦难 / 美化极端 / 制造焦虑 / 强行升华 / 功效暗示 / 真实故事授权。

### 价值观红线（剧情最高风险项）

**不消费苦难**

- 疾病、贫困、残障、丧亲不得作为煽情工具。
- 改法：把苦难变成背景而非卖点——故事重点放在人物如何面对，而不是苦难本身多惨。
- 违规判定：苦难镜头占全片 >30%、苦难直接引出产品功效、用苦难博同情换转化 → 标🟡或🔴。

**不美化极端**

- 自残、暴力、报复、离家出走不得被浪漫化。
- 改法：极端行为只能作为被解决的冲突，不能作为被赞美的选择。
- 违规判定：极端行为被赋予正面结局、被配煽情 BGM、被主角效仿 → 标🔴，整镜重写。

**不制造焦虑**

- 催婚、催生、年龄、容貌、阶层焦虑不得被渲染。
- 改法：呈现现象但不站队，不给「不 XX 就失败」的暗示。
- 违规判定：出现「再不做就晚了」「别人都…只有你…」句式 → 标🟡，给去焦虑改法。

**不强行升华**

- 结尾不喊口号、不硬转品牌、不做「用了产品一切问题都解决了」的过度承诺。
- 改法：情绪自然落地，品牌署名轻露即可。
- 违规判定：结尾旁白突然拔高价值观、产品解决全部矛盾 → 标🟡，给「自然落地」改法。

**其他**

- 真实故事授权：基于真实人物的故事 → 标🟡，提示需授权。
- 儿童 / 老人 / 特殊群体出镜 → 标🟡，提示需授权。

### 逐镜扫描（强制，不得跳步）

每个风险点必须点名它落在哪一镜、属于哪一类、给什么改法。禁止只做总结性过审。

### 标注

每条最终标 🟢 可直接投 / 🟡 需改词改画面（附建议）/ 🔴 整条不可用（说明原因）。

## 5. 四拍情绪归因表（投后诊断用）

| 异常指标   | 归因拍        | 定位动作                 |
| ------ | ---------- | -------------------- |
| 3s 留存低 | Conflict   | 冲突是否具体可演、是否有张力       |
| 中段掉    | Escalation | 情绪是否升级、是否有「想看下一步」的理由 |
| 产品段掉   | Turn       | 产品介入是否自然、是否承担叙事功能    |
| 结尾口碑差  | Resolution | 是否强行升华、是否过度承诺        |
| 评论浅    | 全片         | 是否只有情绪没有共鸣点，观众不想聊自己  |

**诊断动作**：定位到具体镜 → 只给该拍替换建议，不推翻整条。剧情类看的是完播和评论共鸣，不是转化率。

## 6. 分镜表补充（剧情专属）

10 字段与每镜校验见 `references/common/storyboard-format.md`，数值查 `references/common/spec-table.md`。本节只写剧情专属要求：

- 45s 档必须满 7 行，60s 档必须满 9 行（在各自区间内），禁止合并行。
- 每条分镜表前标注：所属钩子 × 冲突、类型（T1–T5）、时长档、调性、风险等级。
- 首镜时效 / 人物关系段时长 → 查 `references/common/spec-table.md` 首镜时效表，不在本文件重复维护。
- 冲突钩子镜 ≤3s；情绪落点镜 ≤5s。
- 台词须标注对白 / 独白，关键台词不超过 3 句，并标出它落在哪个情绪转折点。
- 允许一次「情绪推近」（缓推至特写）作为全片高光，须在分镜表标注。
- 五段式时间轴（45s / 60s 必标）：查 `references/common/spec-table.md`。
- 表尾必附：合计校验行（各镜加总 = 总时长，误差 ≤0.5s）+ 结构段时长分布核对（偏差 >2s 标出并说明）。

## 7. 三模型链路侧重

句式模板见 `references/common/prompts.md`。剧情专属侧重：

- Kling / 可灵：人物关系与表情是重点，动作写「克制、有停顿、有眼神交流」；光影服务情绪（冷光压情绪、暖光放情绪）。
- Veo：英文镜头语言写清人物关系（two people facing each other）、表情（restrained / teary / relieved）与光影变化。
- Runway：参考图优先给人物关系构图参考；运动描述慢，情绪推近只写「slow push-in to close-up」。
- 通用：AI 禁止人物手指崩坏、表情僵硬；关键情绪镜（爆发、和解）建议实拍或多次生成挑选；超 8s 镜头标「分段生成拼接」。
