# TVC 实例 · 参数字段清单（单一真源：调度写 brief + 生成补收）

> 读者有二：① **调度 Agent** 据此写 `workspace/brief.md`（收齐能收的参数，收不齐的标「待生成 Agent 追问」）；② **生成 Agent** 在 Step 2 据此补收 brief 里标「待追问」的字段（不重复收 brief 已收齐的）。字段定义与默认值以本表为准。

## 通用字段（三链路共用）

| 字段 | 说明 | 默认值（未指定时） | 链路覆盖 |
|---|---|---|---|
| 产品 + 品类 | 卖什么 | 必填 | 全链路 |
| 人群 | 谁看 / 谁用 | 必填 | 剧情由「人物关系」替代 |
| 卖点 | ≤3 个 | 必填 | 软广由「产品带来的改变」替代；剧情由「产品功能」替代 |
| 价格 | 可弱化（软广） | 视链路 | 全链路 |
| 预算档位 | 低成本棚拍 / 中成本实景 / 高成本大片 | 中成本实景 | 全链路 |
| 平台 | 抖音 / 小红书 / 视频号 / B站 等 | 抖音 | 全链路 |
| 画幅 | 9:16 / 16:9 | 9:16 | 全链路 |
| 时长 | 15s / 30s / 45s / 60s | 45s | 全链路 |
| 风格 | 纪实 / 氛围 / 快节奏 等 | 视链路 | 全链路 |
| 调性 | 见各链路调性池 | 视链路 | 全链路 |
| 质感 | 画面材质感（高级/胶片/生活纪实 等） | 视链路 | 硬广专属（可选） |

> 「链路覆盖」列说明：标「由 X 替代」的字段，该链路收信息时用 X 替代本字段，不重复收；调度 Agent 写 brief 时按此规则留空替代字段。

## 链路专属默认值

| 链路 | 类型默认 | 画幅 | 平台 | 风格 | 时长 |
|---|---|---|---|---|---|
| hard-ad | C 剧情（A 测款 / B 种草 / C 剧情 / D·AI） | 9:16 | 抖音 | 生活化纪实 | 45s |
| soft-ad | S2 场景种草（S1 生活记录 / S2 场景种草 / S3 情绪叙事 / S4 价值观表达） | 9:16 | 小红书 | 生活化纪实 | 30s |
| story-ad | T1 情感向品牌片（T1-T5） | 9:16 | 抖音 | 真实纪实 | 45s |

## 链路专属字段（在通用字段之外，或替代通用字段）

- hard-ad：质感（可选，画面材质感）
- soft-ad：产品带来的改变（替代「卖点」）/ 价格（可弱化）
- story-ad：人物关系（替代「人群」）/ 冲突点（具体可演的一件事）/ 产品功能（解扣/载体/信物/佐证，替代「卖点」）/ 目标情绪

## 选项联动（收信息时给出建议，标「我替你选了 X，要改直接说」）

> 本节的「选项联动」是**生成 Agent Step 2 收信息时**用的提示（调度 Agent 只写 brief 不做联动建议）。完整联动规则以各链路 skill.md 的「选项联动」为准，本节是快速速查，三链路都要覆盖。

### 硬广

- 平台抖音信息流 → 15s 快节奏、前 3 秒强钩子
- 预算低成本 → 单场景/棚拍，避免外景大片
- 人群年轻女性 → 生活化纪实而非高级氛围
- 卖点价格优势 → 15s 测款 + 对比打脸调性

### 软广

- 平台小红书 → 30s 生活化纪实、封面文字轻、正文有共鸣点
- 平台抖音 → 15–30s、前 3 秒生活切片要真实
- 预算低成本 → 单场景/家居实景
- 人群新手妈妈 → S2 场景种草 + 温情治愈调性
- 产品改变「省时间」→ S2 场景种草 + 真实记录调性

### 剧情

- 平台抖音 → 45s 强冲突、前 3 秒给冲突瞬间
- 平台视频号 → 60s、情绪曲线完整
- 预算低成本 → 单场景/室内对话
- 目标情绪温情 → T1 + 温情催泪调性
- 人物关系父子 → 冲突点「说不出口的话」，产品作信物
- 目标情绪燃 → T5 轻喜剧或 T3 连载短剧 + 燃向逆袭调性
