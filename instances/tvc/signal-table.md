# TVC 实例 · 链路信号词表

## 一、按信号词分派

| 信号词 | 分派链路 |
|---|---|
| 硬广 / 带货 / 投流 / 千川 / 转化 / ROI / CTA / 卖点直给 / 测款 / 爆款拆解 | → hard-ad |
| 种草 / 软植入 / 生活方式 / 原生内容 / 收藏率 / 评论深度 / 松弛感 / 生活切片 | → soft-ad |
| 剧情 / 情感向 / 品牌故事 / 节庆大片 / 人物冲突 / 催泪 / 反转 / 微电影 | → story-ad |

> **链路标识即 header `chain` 字段取值**：调度 Agent 写 brief.md 时，`chain` 字段填本表的链路标识 `hard-ad` / `soft-ad` / `story-ad`（带 `-ad` 后缀），与目录名、生成 Agent 名保持一致，不缩写为 `hard`/`soft`/`story`。下游按 `chain` 值路由时直接对应目录与 Agent。

## 二、信号不清时，按第一目标判定

- 记忆产品卖点 → 硬广
- 留下内容记忆点 → 软广
- 留下情感记忆点 → 剧情

品类同时符合两类时（如功效护肤可硬可软），以第一目标为准，不以品类标签为准。

## 三、仍判不准时追问

你要的是**转化**（硬广）、**种草**（软广）还是**品牌故事**（剧情）？

## 四、互斥规则

剧情类禁止强痛点 CTA；硬广禁止文艺留白与氛围前置；软广禁止产品说明书式叙事。三类不得混用。

## 五、链路意图（生成 Agent Step 1 判）

每条链路内再判具体意图：拆爆款 / 生成脚本 / 投后诊断。
