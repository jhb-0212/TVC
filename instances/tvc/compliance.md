# TVC 实例 · 过审规则（过审 Agent 用）

## 一级违禁词替换表 + 数据引用原则

**单一真源在 `chain/references/common/compliance-base.md`**（三链路通用，生成 Agent 对标时也读它）。过审 Agent 直接读该文件的「一级违禁词替换表」和「数据引用原则」，本文件不重复维护，避免双份。

> 速记：违禁词查 compliance-base.md；本文档只管「过审专属」的创作自检 + 二级项 + 逐镜扫描。

## 创作自检清单（第一级，按链路）

- **hard-ad 5 条**：卖点唯一且可视化 / 前 3 秒直接给冲突或结果 / 每 3 秒信息推进 / 记忆点可模仿 / CTA 具体到动作。
- **soft-ad 5 条**：产品自然融入 / 痛点隐性 / 人物真实无广告腔 / 有可传播主张 / 结尾克制。
- **story-ad 6 条**：冲突具体可演 / 产品承担叙事 / 情绪曲线完整 / 台词精炼 / 结尾自然 / 记忆点是情绪瞬间。

## 二级项 + 链路专项（第二级）

| 链路 | 专项 | 最高风险项 |
|---|---|---|
| hard-ad | 功效/数据宣称/前后对比/贬低竞品 + 行业附加 | 功效绝对化 |
| soft-ad | 功效暗示专项 + 虚假场景🔴 + 焦虑暗示 | 功效暗示（因果暗示即违规） |
| story-ad | 价值观红线（不消费苦难/不美化极端/不制造焦虑/不强行升华） | 消费苦难 |

## 逐镜扫描（强制，不得跳步）

- 每个风险点必须点名落在哪一镜、属于哪一类、给什么改法。
- 每个数字必须点名落在哪一镜、属于哪一类、如何处理。
- 禁止只做总结性过审。

## 出镜授权（硬前置，投放前必查）

- 儿童 / 老人 / 素人 / 特殊群体出镜，或基于真实人物的故事，**出镜书面授权是投放前硬前置**。
- 过审 Agent 必须**主动检查** brief 或脚本是否含此类出镜，并写进 review.md 结论：**未取得授权 → 标 🔴 禁投**（不是🟡建议，是禁投级）；已取得 → 标 🟢 并在结论注明「已确认授权」。
- 生成 Agent 常不主动提授权，过审 Agent 不得因此跳过此项。
